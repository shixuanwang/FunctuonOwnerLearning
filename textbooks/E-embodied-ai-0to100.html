① 全景与生态地图：机构 / 范式 / 数据规模

具身智能（Embodied AI）= "感知 → 决策 → 动作"在物理世界的闭环。和自动驾驶（AD）相比，最大差别是：AD 是单 embodiment（车）+ 高频闭环评测（接管率/碰撞率）+ 海量车队日志红利；具身是多 embodiment（机械臂/双臂/人形/底盘，DOF 7/14/29/57）+ 评测碎片化（CALVIN/LIBERO/RoboTwin/EmbodiedScan/OpenEQA 各管一摊）+ 数据靠遥操作/合成/示教硬采。这两个差别决定了 PM 的转战卡位：你的 AD 数据闭环肌肉记忆可直接迁移，但要补"硬件 teleop + sim-to-real + 跨本体统一表征"这三块 AD 几乎不涉及的能力。

具身 2024-2025 的范式已收敛到 VLA = VLM backbone + action head：把图像/语言送进视觉-语言模型提语义表征，再接一个动作头生成连续或离散的动作输出。这一范式在 AD 端到端里其实是同构的（感知 → 意图 → steering/throttle/brake），差别只在 action space（轨迹 vs 末端执行器位姿）和 embodiment 维度。所以判断力可迁移，术语和工程细节要重学。

0.4 范式分化的两条主干

VLA 在 action head 上分化为两条主干，2024-2025 明显从 (A) 迁向 (B)：

  • A 派离散 action token 自回归（RT-1 → RT-2 → OpenVLA）：把 7 维动作 256-bin 离散化成 7 个 token，自回归一个一个吐。优点：复用 LLM 训练栈、可 CoT；缺点：难兼顾高频（2-10Hz）和多模态动作分布。
  • B 派连续动作生成（diffusion / flow-matching）（π0 / RDT / CogACT / GR00T System-1）：用去噪扩散或 flow matching 一次出一段 action chunk（H=16~50），可达 50-120Hz。优点：高频灵巧 + 多模态；缺点：训练贵、推理需去噪步数。
迁移判断（强）：AD 端到端模型本质就是 VLA（图像 + 意图 → steering/throttle/brake）。RT-1 的 FiLM EfficientNet + Tokenizer + Transformer + 256-bin 几乎就是早期端到端 AD 驾驶网络的同构；π0 的 flow-matching action head 与 AD 里轨迹 diffusion planner（MDP/Ego-Planner）同源。AD PM 对"感知→动作映射"的产品理解可直接平移，只需把 action space 从"轨迹"换成"末端执行器位姿"。

② VLA 范式本质：为什么是 VLA、IL/RL、token vs continuous、flow-matching

1.1 什么是 VLA（Vision-Language-Action）

VLA = 一个端到端神经网络，输入图像观测（+语言指令 +机器人状态），输出机器人动作。它把 AD 里的"感知 → 预测 → 规划 → 控制"四段式折叠成一个 token 序列到 token 序列（或图像表征到动作 chunk）的映射。本质：把大模型语义能力（识别物体、理解指令、推理常识）迁移到连续控制。

VLA 概念正式提出是 Google RT-2（2023.07）——co-fine-tune 已有 VLM（PaLM-E 12B / PaLI-X 55B），把动作表达成文本 token（如 1 128 91 241 5 101 127 217），推理时 de-tokenize 回动作。这条路线被 OpenVLA（7B，开源事实标准）继承。

为什么 VLA 必要？前 VLA 时代（RT-1 35M 2022.12）已证明"高效 Transformer + 离散 action token + 大规模真机数据"能做到 97%（见过的任务）/76%（未见）成功率，但语义能力靠视觉分类硬学，无法 web-scale 迁移。RT-2 的突破是证明 web 语义知识（符号理解、推理、人识图）能直接迁移到机器人动作，emergent 能力比基线提升 3×。这把 VLA 从"感知映射"升格为"通用智能体"，是范式分水岭。

1.3 Action Token 化 vs 连续动作生成：本节最核心的范式判断

难点：action token 化到底是什么。RT-1/OpenVLA 把连续动作的每一维按 1st-99th 分位数切成 256 个 bin，每个 bin 对应一个 token id（像词表）。7 维动作（x/y/z/roll/pitch/yaw/gripper）→ 7 个离散 token，自回归生成。本质是把连续回归问题改造成分类问题，从而复用 LLM 的 next-token prediction 训练栈。代价：(1) 量化误差（256-bin 精度有限）；(2) 必须逐 token 生成，无法并行，导致高频任务（如灵巧手 50Hz）做不到；(3) 单峰输出，难表达"多种合理动作"的多模态分布。这就是 B 派出现的根本原因。
难点：flow-matching 是什么。Flow matching 是 diffusion 的近亲：把"从噪声到动作"建模成一条连续流（ODE），训练时学速度场 v(x,t)，推理时从纯噪声积分到动作。相比 diffusion：(1) 路径更直，去噪步数少（K=4 即可）；(2) 数学更简洁（无 score function）。π0 用 flow matching 在 4090 上跑 50Hz 灵巧任务，是 B 派的工业级标杆。类比 AD：AD 里的轨迹 diffusion planner（MDP/Ego-Planner）是同一族方法，只是 action space 是轨迹点列而非末端位姿。

1.4 Action Chunking：对抗 compounding error 的关键技巧

ACT（Action Chunking with Transformers，ALOHA 配套算法，RSS 2023）提出：policy 一次预测一段 action（chunk），而非单步。原因：IL 单步预测会让误差累积（compounding error）—— 小误差导致下一帧观测偏离训练分布 → 预测更大误差 → 雪崩。chunk 一次出 H 步，执行时用 ReActing 机制（每步重新观测但只在 chunk 边界重预测）缓解。这条被 Pi0/Pi0.5（H=50）、GR00T N1（H=16）、CogACT（H=16）、RDT 几乎所有现代 VLA 复用。

action chunking 是理解现代 VLA 的最关键单一概念。它对应 AD 里的"轨迹预测"（一次出 N 个未来轨迹点 vs 一次出 1 个）。AD PM 已有"多步预测 vs 单步预测"的权衡直觉（多步稳但延迟高、误差传播模式不同），可零成本迁移。差别只在具身的 chunk 跨控制周期（毫秒级），AD 的轨迹跨秒级。

1.5 VLA 训练范式：Pre-train → Post-train 两段式（从 LLM 平移）

π0、GR00T N1、RT-2 都明确采用"大规模预训练 + 任务/机器人特定后训练（含 LoRA 微调）"范式。这把 VLA 从"每个任务训一遍"升级为"基座 + 微调"，是工业化的关键信号。

  • Pre-train：吃跨 embodiment 大数据（OXE 1M / OpenVLA 970K / GR00T 数据金字塔 6500h / π0 10kh）训通用 policy。
  • Post-train：在特定机器人/任务上 LoRA 或全参微调。OpenVLA LoRA 单 A100 10-15h 可跑（1.4% 参数追平全参），是中小团队主力路径。
迁移判断（强）：AD PM 已掌握"基座模型 + 任务微调"的判断力（如 BEVFormer/Nuscenes 预训练 → 下游微调）。VLA 的 pre-train→post-train 是同一思想，可直接迁移成"VLA 选型 + 微调"的产品决策能力。具体决策树：先定任务（操作/导航/bimanual）→ 选规模（小 Octo 93M / 中 RDT 1.2B / 大 OpenVLA 7B / 旗舰 π0 3.3B / GR00T 2.2B）→ 选 action head（离散 token / diffusion / flow matching）→ 选数据（OXE 开放 / 自采 teleop / Isaac Sim 合成）。

1.6 跨 embodiment 统一：具身界的"多传感器统一表征"问题

AD 是单一 embodiment（车），但具身是 cross-embodiment（单臂 DOF 7 / 双臂 14 / 人形 29 / 底盘 57...）。各家做法：

  • Open X-Embodiment：用统一 7 维 end-effector delta/abs/velocity 动作空间，22 种形态机器人的数据能互相增益，RT-X 在很多下游形态上超过各单形态训练。
  • π0：用 18 维 configuration vector 统一不同机器人。
  • Cosmos：覆盖 single-arm(10D)/dual-arm(20D)/humanoid(29D)/AV(9D)/camera-motion(9D)/egocentric(57D) 多 action 空间。
  • RoboBrain-X0（智源）：Grouped Residual Quantizer (GRVQ) 把不同机械结构映射到共享 Unified Action Vocabulary (UAV)，用 SE(3) 任务空间末端位姿做跨本体统一。直接对标 Physical Intelligence。
类比锚点：cross-embodiment 统一 ≈ AD 的"多车型/多传感器配置泛化"。AD PM 做"多车型 BEV 统一表征"的肌肉记忆（不同相机数/不同分辨率/不同 LiDAR 线数归一化）可直接迁移成"多机器人 action space 统一"的判断力。差别：AD 是感知层归一化，具身是动作层归一化（更难，因为物理 DOF 不同）。

3.1.1 GR-1 — 视频生成预训练驱动机器人操作的开山作

ICLR 2024 清华 IIIS + ByteDance github.com/bytedance/GR-1 · 约 310 stars · 通讯/共作者 Tao Kong（清华 IIIS + ByteDance）

  • 架构：GPT-style autoregressive Transformer。输入 = 语言指令 + 图像观测序列 + 机器人状态序列。视觉 backbone = MAE ViT-Base（Facebook 预训练）。统一输出 = 机器人动作（next-token）+ 未来图像（generative）。本质：把 video generation 与 action prediction 合并进一个 causal LM 目标，用 action token + image token 拼接。
  • 训练：两阶段。(1) 在大规模互联网视频（Ego4D 类，数千万~亿级 tokens，论文未完全披露）做视频生成预训练；(2) 在 CALVIN benchmark（数千 episodes，ABCD split）做机器人 fine-tune。算力未公开，涉及多卡训练。
  • 数据：预训练 = 大规模无标注互联网视频；Fine-tune = CALVIN（开源 PyRobot / RoboSuite 仿真基准，34 个任务）。GR-2 后续扩到 38M 视频 + 真机数据。
  • 创新点：首次系统证明"video generative pre-training"能极大提升机器人 manipulation 泛化能力（零样本未见场景 53.3%→85.4%，CALVIN 88.9%→94.9%）。把 video generation 的 representation 当通用物理先验，再接 action head —— 这是后来 GR-2 / VPP / Pi-0 类"世界模型驱策略"路线的起点。
  • 可复现度：中-高。代码 + 预训练权重 + 评测脚本（evaluate_calvin.py）都开放（MIT license）。但仓库以评测为主，训练代码非完整流水线（只有 fine-tune 入口）。需自行下载 MAE 权重、CALVIN 数据、GR-1 checkpoint。社区第三方 EDiRobotics/GR1-Training 复现了训练侧。

3.1.2 VPP（Video Prediction Policy）— 清华系开源质量最高的 VLA

ICML 2025 Spotlight 清华 IIIS / Jianyu Chen + UC Berkeley + RobotEra + Shanghai AI Lab github.com/roboterax/video-prediction-policy · 约 408 stars · arXiv:2412.14803

  • 架构：两段式。(1) Video Prediction Model = Stable Video Diffusion (SVD) 微调版，在 latent 空间预测未来视觉表征，CLIP vit-base 文本编码器（冻结）。(2) Action Head = 隐式 Inverse Dynamics Model，用 diffusion transformer policy（基于 MDT）在 SVD 中间表征上回归动作。不是直接用 SVD 出图，而是抽取 latent representation 作 policy 输入。
  • 训练：硬件 8× A800/H100。数据 Something-Something-V2（预训练）、Bridge、RT-1、CALVIN ABC（500GB）、RobotEra xhand/x-bot 真机演示。两阶段：先把 SVD 在机器人视频上微调，再训 inverse dynamics policy。提供 accelerate 分布式脚本。
  • 数据：开源预训练模型 HuggingFace: svd-robot, svd-robot-calvin, dp-calvin。混合开源仿真（CALVIN）+ 真机遥操数据集（RobotEra）。真机侧号称单策略解 100+ 真实灵巧操作任务。
  • 创新点：把"video diffusion model 的内部表征"当作机器人 policy 的世界先验，而不是用生成图作为监督 —— 证明 VDM 内部 hidden state 含足够物理因果信息，反动力学（给定当前态 + 预测未来，反推动作）是高效策略范式。和 GR-1 一脉相承但更彻底（完全不需要生成可见图像）。
  • 可复现度：高。HF 预训练权重 + 训练脚本（仿真+真机部署）+ CALVIN 评测管线完整开源。8 卡可复现。是清华系 VLA 中开源质量最高的之一，也是推荐的入门 repo。

3.1.3 RoboFlamingo — 把 OpenFlamingo 迁到机器人操作的范式奠基

arXiv:2311.01378 清华 IIIS + ByteDance github.com/RoboFlamingo/RoboFlamingo · 约 438 stars · 484+ 引用

  • 架构：Backbone = OpenFlamingo 框架（CLM cross-attention），视觉编码 OpenCLIP ViT-L/14，LLM 支持 MPT / RedPajama / LLaMA / OPT / GPT-Neo / GPT-J / Pythia。Action Head = LSTM 解码器（每步输出相对动作），另支持 FC / Diffusion / GPT 解码器。cross_attn 每 N 层插入一次（可配置）。Per-step relative action 输出。
  • 训练：数据 CALVIN benchmark（ABCD 与 ABC split）。Window=12 步，batch=6/GPU，8× A100 DDP。可选与 VL 数据集（COCO/VQA）co-training 以防 VLM 能力遗忘。算力门槛低：单台 GPU server 可跑。
  • 创新点：首次系统证明"冻结/微调大 VLM（OpenFlamingo）可直接当机器人 policy 用"，在 CALVIN 上以大 margin 刷到 SOTA。奠定 VLA = 大 VLM + 轻量 action head 这一主流范式，是 OpenVLA、SpatialVLA、Pi-0 的重要前作。
  • 可复现度：高。MIT license，requirements + bash 脚本（pt_run_gripper_post_ws_12_traj_aug_mpt_dolly_3b.bash）+ HF 权重 + eval_ckpts.py 完整。是清华系里"从跑通到训完"工程最干净的 repo 之一。

3.1.4 GR-MG — 半标注数据利用的工业级范式

ByteDance Research + 中科院自动化所 github.com/bytedance/GR-MG

  • 架构：多模态目标条件策略。用 InstructPix2Pix 类模型从"语言 + 部分标注"生成目标图像（goal image），再接 MAE encoder + CLIP，基于动作目标图像回归动作。可视为 GR-1 的"goal image"增强版。
  • 训练/数据：预训练 Ego4D 视频；评测 CALVIN。多卡训练。代码 + checkpoint + 训练/评测脚本齐全。
  • 创新点（对数据闭环 PM 极有启发）：把 GR-1 的 video-prediction 先验 + 显式 goal image 生成结合，处理工业级"半标注"数据 —— 不是所有真机数据都有完整图像-动作对，goal image 合成是一种数据增强/补全范式。这对应 AD 里的"部分标注场景挖掘"。
  • 可复现度：高。ByteDance 系 repo 工程质量稳定。

3.1.5 RDT-1B + CogACT — 清华 thu-ml 的 diffusion action head 路线

RDT-1B ICLR 2025 github.com/thu-ml/RoboticsDiffusionTransformer · 803+ 引用 · 1.2B 参数（最大 diffusion 机器人基座之一）

  • 架构：MMDiT（Multimodal Diffusion Transformer）。把异构机器人动作空间统一编码；bimanual action 空间 128 维（2 臂×64）。BPE action tokenization + 去噪扩散，条件输入：本体感知、noisy action chunk、控制频率、diffusion timestep、图像、语言。
  • 训练：64× A100 预训练 1M+ episode（46 数据集）；ALOHA 双臂 6K+ episode 微调（业内最大之一）。推理 6 action chunk/s（381 action/s）。
  • 创新点："diffusion transformer 做 bimanual 基座"路线代表。1-5 demo 即可 few-shot 迁移。双臂/dexterous 方向必看基线。

CogACT github.com/microsoft/CogACT · 385+ 引用 · 三档 DiT-S/B/L

  • 架构：Prismatic VLM 主干（SigLIP + LLM）+ 独立 Diffusion Transformer action head。核心：用"单个 cognition token 触发整个动作序列"的 diffusion 生成，而非 OpenVLA 那样为 7 维动作生成 7 个 token。一次推理输出 16 步 7-DoF 动作。
  • 性能：A6000 bf16 上 CogACT-Base ~181ms/推理（5.5Hz），比 OpenVLA（~307ms，1 action/次）快 ~1.7× 且单次出 16 action。
  • 创新点："认知/动作解耦"的架构主张——VLM 只负责语义，专用 diffusion 动作头承担多模态动作分布。"OpenVLA 派 vs π0 派"之外的第三条路。
清华系路线总结："视频生成预训练 → 机器人微调"是清华系（ByteDance + THU）路线主旋律——GR-1（生成视频）、VPP（隐式 SVD 表征）、GR-MG（goal image）都把"video generative model 的内部表征"当通用物理先验，再接轻量 action head。这与清华在 world model / video diffusion 上的长期积累一致，与 OpenVLA（纯 OpenX 监督）是两条不同路线。Action Head 设计趋同：diffusion / flow-matching 已是事实标准。评测高度集中在 CALVIN，跨论文可比性强，但也暴露"仿真数据闭环"和"真机泛化"gap 是主要矛盾 —— 与 AD sim2real 痛点同构。

3.2.1 RoboBrain 系列（BAAI）— 国内最早系统性具身大脑统一模型

RoboBrain / ShareRobot CVPR 2025 github.com/FlagOpen/RoboBrain · 176+ 引用 · Apache-2.0

  • 架构：基于 LLaVA-NeXT 的 MLLM（3B/7B/32B 三档）。核心是用 LoRA 把三类能力挂到统一基座：Planning-LoRA（任务分解）、Affordance-LoRA/A-LoRA（可交互物体感知）、Trajectory-LoRA/T-LoRA（末端执行器轨迹预测）。本质是"感知-规划-控制"三段式统一到一个大模型 token 序列里。
  • 训练：多阶段。Stage1 通用预训练 → Stage1.5 直接 SFT → Stage2 resume fine-tuning (si/ov) → Stage3 机器人规划数据训练 → Stage4 用 LoRA 训 affordance+trajectory。每节点 8× A800 GPU。在 ShareRobot 上训练后任务分解 BLEU-4=55.05%，提升 30.2%。

  • 创新点：把"抽象（指令/规划）→ 具体（affordance+轨迹）"端到端塞进一个 MLLM，并用 ShareRobot 多维度对齐标注做监督。是国内最早系统性提出"具身大脑统一模型"并配套开源大规模细粒度标注数据集的工作之一。
  • 可复现度：高。权重(HF)、训练脚本、推理代码、数据集(HF+GH)、评测 benchmark 全部开源。8× A800 单节点即可复现，国内具身大脑里复现门槛最友好的之一。

RoboBrain 2.5（Depth in Sight, Time in Mind） github.com/FlagOpen/RoboBrain2.5 · 2025 悟界系列

  • 可复现度：中-高。4B/8B 权重和推理代码已开源；32B 和训练代码在 todo。国产摩尔线程版本的可复现性是独特卖点。

RoboBrain-X0（Cross-Ontology Foundation Model） github.com/FlagOpen/RoboBrain-X0

  • 架构：RoboBrain 2.0（多模态理解）+ OmniSAT 动作 tokenizer。核心是 Grouped Residual Quantizer (GRVQ)：把不同机械结构的连续控制序列映射到一个共享的离散"动作原语"空间（Unified Action Vocabulary, UAV），用 SE(3) 任务空间里的末端执行器位姿做跨本体统一表示。
  • 创新点：国内首个明确把不同机器人本体统一到一个动作词表的 VLA。SE(3) 任务空间 + UAV 是方法论核心，直接对标 Physical Intelligence 的跨本体思路。Docker 环境：CUDA 12.4.1 / cuDNN 9.5 / Python 3.12 / PyTorch 2.6，要求共享内存最高 512GB。
  • 可复现度：中。preview 权重(HF) + 多芯片版 + 训练数据集 + 多平台推理示例（Agilex/Franka/R1-Lite ROS1/ROS2/A2D）已开源；完整训练流程和算力配置不透明。

  • 架构："大脑-小脑"分层三件套：(1) Embodied Cloud Model = MLLM 全局感知+高层决策；(2) Cerebellum Skill Library = 即插即用模块化技能库；(3) Real-Time Shared Memory = 基于 Redis 的时空同步机制。RoboOS 2.0 升级为 SaaS + MCP 架构，Master-Slaver 多机协同。

3.4.4 OpenVLA — 开源 VLA 事实基线

  • 可复现度：高。代码、权重、训练 recipe、微调脚本（LoRA/OFT/全参）全开，文档好，社区 fork 多。算力门槛相对友好（单 A100 可微调），是 VLA 训练基建标杆。

3.4.5 RT-1 / RT-2 — VLA 范式奠基（权重闭源）

RT-1（arXiv:2212.06817，未开源权重）：~35M 参数。FiLM EfficientNet（ImageNet 预训练）做图像 token 化，按指令 embedding 做 FiLM 调制；Token Learner 压成紧凑 token 集；Transformer 自注意输出离散 action token。action 空间：7 维臂 + 3 维底盘 + 1 维模式切换；每维 256-bin。3Hz 闭环控制。训练 130K episode / 700+ 任务，13 台 Everyday Robots 真机采集 17 个月。奠定"离散 action token + 大数据真机"的 VLA 工程范式。

RT-2（arXiv:2307.15818，未开源权重）：Co-fine-tune 已有大 VLM 直接当 VLA。两版：RT-2 PaLM-E（12B，另有 5B 消融）/ RT-2 PaLI-X（55B）。action 同 RT-1 的 256-bin，但表达成文本 token（如 1 128 91 241 5 101 127 217）。首次正式提出 VLA 概念，是整个西方 VLA 路线的源头。

3.4.6 Physical Intelligence π0 / π0.5 — flow-matching 分水岭

openpi ~13k stars · π0 被引 2500+ · π0.5 被引 946+ arXiv:2410.24164 · Apache-2.0

  • 架构：3.3B 总参：PaLI-Gemma 3B VLM 主干 + ~300M 独立 action expert（与 VLM 权重分开）。核心：Flow Matching action head——不再像 RT-2/OpenVLA 那样把 action 离散成 token 自回归，而是用 conditional flow matching 训练一个连续动作生成头，输出 50 步 action chunk（H=50）。4090 上 50Hz 灵巧任务、20Hz 标准 arm。
  • 训练：10,000 小时机器人数据：自采 903M timestep（106M 单臂 + 797M 双臂）+ OXE/Bridge v2/DROID（占 9.1%）。7 种自家机器人配置（UR5e/Franka/Trossen/ARX/AgileX/Mobile Fibocom 等）+ 22 种 OXE 机器人 cross-embodiment 共训。68 个任务。Pretrain→post-training 类 LLM 范式。
  • 创新点：Flow matching 取代离散 action token——彻底解决"高频 + 多模态动作分布"问题（自回归离散 VLA 难做 50Hz）。action expert 与 VLM 权重解耦，VLM 提供语义、action expert 提供高频控制。是西方 VLA 从"离散 token"转向"连续 flow"的分水岭。
  • π0.5（arXiv:2504.16054）：π0 升级版，仍是 flow-matching VLA，但加入 high-level 语义预测/规划层，把"open-world generalization"作为第一目标（unseen home/object）。π0.5-LIBERO 仿真 benchmark SOTA。是 VLA 从"lab 通用"迈向"in-the-wild 通用"的关键一步。
  • 可复现度：中-高。openpi 开源 base checkpoint + 全训练 pipeline（PyTorch/JAX）+ LoRA 微调（ALOHA/DROID/LIBERO/UR5/SO-100/LeKiwi）。但完整 10kh 数据非全公开，1:1 复现受限；微调与推理对中小团队友好。

3.4.7 Octo — 轻量 + 灵活接口 + 易微调（教学/研究最佳入门）

RSS 2024 · 1700+ 引用 github.com/octo-models/octo · Octo-Small 27M / Octo-Base 93M · Apache-2.0

  • 架构：Transformer-based diffusion policy。核心是"readout token"机制：用可学习的 readout token 做任务/观测的灵活接口（语言 or 目标图，单/多相机），diffusion head 解出多模态动作分布。JAX 实现。
  • 训练：800K Open X-Embodiment episode（25 个数据集混合），跨 embodiment/传感器/标注异构统一训练。算力未详列，规模远小于 7B 级 VLA。
  • 创新点："轻量 + 灵活接口 + 易微调"路线代表：93M 就能在 OXE 上训出通用 policy，且 readout token 让它优雅地适配新机器人/新传感器（force-torque、新相机、新动作空间），~100 demo 即可微调。是 VLA 里"小而美"的开源标杆，与 7B 级形成互补。
  • 可复现度：高。代码、权重、训练/微调脚本全开，JAX 生态完善，算力门槛低（消费级 GPU 可微调）。是教学/研究的最佳入门 VLA 之一。

3.4.8 3D-VLA — 3D-aware VLA + 生成式世界模型

ICML 2024 · 393+ 引用 github.com/UMass-Embodied-AGI/3D-VLA

  • 架构：把 3D 感知/推理/动作统一进一个 embodied foundation model。LLM 主干（基于 Vicuna 系）+ interaction tokens 与环境交互。双 diffusion 生成组件：(1) Goal Image Generation（latent diffusion，基于 InstructPix2Pix + Stable Diffusion，可选深度）；(2) Goal Point Cloud Generation（fine-tune Point-E）。输入 3D 点云（.npy）。
  • 创新点："VLA + generative world model + 3D"三合一：用生成式世界模型做"目标图/目标点云生成 + 动作规划"，引入显式 3D 表征，弥补 2D VLA 对空间几何理解的不足。是"3D-aware VLA"方向的代表作。
迁移判断（直接·强）：AD 端到端模型本质就是 VLA（图像/感知 + 意图 → steering/throttle/brake）。RT-1 的"FiLM EfficientNet + Tokenizer + Transformer + 256-bin action"几乎就是早期端到端 AD 驾驶网络的同构；π0 的 flow-matching action head 与 AD 里轨迹规划的连续输出/多模态轨迹分布高度同构。AD PM 对"感知→动作映射"的产品理解可直接平移。
避坑提示：不要把 AD 的"里程数=数据量"直觉直接套到 VLA。VLA 数据质量（teleop 质量、任务多样性、cross-embodiment 覆盖）远比纯数据量重要——π0 10kh 数据里只有 9.1% 是开放数据但效果顶级，OpenVLA 970K 全开但仍被 π0 碾压。"数据质量 + embodiment 多样性 + 任务覆盖"三位一体才是 VLA 数据产品的核心。

3.6.7 Sim-to-real 三件套（行业默认）

  • ① Domain Randomization (UDR)——仿真时随机化物理/视觉参数（摩擦/质量/光照/纹理），训出的 policy 对分布偏移鲁棒。

  • ③ Dynamics Randomization + 系统辨识——随机化动力学参数 + 用真机数据辨识仿真器参数，缩小 sim-real 物理差。

5.4 多模态通道补全（力觉/触觉是新增蓝海）

从纯 RGB → +wrist cam（ALOHA）→ +深度（DROID stereo）→ +力觉/触觉（RoboMIND 2.0 / AgiBot World 视触觉）。力觉通道是当前相比 AD（多 LiDAR/多相机）最缺、增长最快的方向。

机会点（差异化竞争力）：RoboMIND 2.0/AgiBot World 视触觉是新增且无标准格式的蓝海，把 AD 多模态时序对齐经验迁过来定义力觉数据 schema 与评测指标，可能做出行业级贡献。这是你相对其他 AD PM 的差异化机会。

5.5 Action Chunking 是 VLA 默认范式（理解具身 policy 的最关键单一概念）

ACT（ALOHA 配套）一次预测一段 action（而非单步）以对抗 compounding error，被 Pi0/π0、GR00T、SmolVLA、CogACT 等几乎所有现代 VLA 复用。对应 AD 里的"轨迹预测"（一次出 N 个未来轨迹点 vs 一次出 1 个）。

难点：compounding error 是什么。IL 单步预测会让误差累积：小误差导致下一帧观测偏离训练分布 → 预测更大误差 → 雪崩。chunk 一次出 H 步，执行时用 ReActing 机制（每步重新观测但只在 chunk 边界重预测）缓解。AD PM 已有"多步预测 vs 单步预测"的权衡直觉（多步稳但延迟高、误差传播模式不同），可零成本迁移。差别只在具身的 chunk 跨控制周期（毫秒级），AD 的轨迹跨秒级。

5.6 跨具身体泛化是新圣杯（对应 AD 多车型泛化）

Open X（22 形态）+ RoboMIND（6 形态）+ AgiBot World（多平台）都在攻"一份 policy 多机器人"。对应 AD 里"多车型/多传感器配置泛化"。各家做法：Open X 用统一 7 维 EE delta/abs/velocity；π0 用 18 维 configuration vector；Cosmos 覆盖 10/20/29/9/57D 多 action 空间；RoboBrain-X0 用 GRVQ+UAV+SE(3) 任务空间。

⑥ 训练基建：算力 / 分布式 / sim

6.1 VLA 训练基建收敛到三件套

  1. 跨本体统一数据格式——OpenX/OpenVLA 970K demo、LeRobotDataset MP4+Parquet。
  2. 大骨干——Llama-2 7B / Prismatic VLM（OpenVLA）；PaliGemma（π0）；Eagle-2 + SmolLM2（GR00T）。SigLIP 系 vision encoder 几乎成事实标准。这意味着做 VLA 不必自研 VLM，关键是 action head + 数据。
  3. 大 batch + 数十卡训数周——OpenVLA 64×A100×14d ≈ 21,500 A100-h，batch=2048；GR00T N1 50,000 H100-h，峰值 1024 GPU，OSMO 编排。

开源基线已把 VLA 拉到可复现。但完整复训成本极高（数万 A100-h），多数人走 LoRA 微调路径（OpenVLA LoRA 单 A100 10-15h，1.4% 参数追平全参）。

6.2 Pre-train → Post-train 两段式（从 LLM 平移）

π0、GR00T N1、RT-2 都明确采用"大规模预训练 + 任务/机器人特定后训练（含 LoRA 微调）"范式。这把 VLA 从"每个任务训一遍"升级为"基座 + 微调"，是工业化的关键信号。

  • Pre-train：吃跨 embodiment 大数据（OXE 1M / OpenVLA 970K / GR00T 数据金字塔 6500h / π0 10kh）。
  • Post-train：在特定机器人/任务上 LoRA 或全参微调。OpenVLA LoRA 单 A100 10-15h 可跑，是中小团队主力路径。

6.4 Replay Buffer / 数据飞轮的范式迁移

洞察一：转战具身的最高杠杆点不是"学模型"而是"做数据闭环 PM"

国内具身界模型人才井喷（清华/北大/SJTU/智源/上海 AI Lab），但能把 ShareRobot 这种多维度对齐数据集从 0 设计到 5 万 episodes、并配评测体系的人极少。你的 4 年 AD 数据闭环 PM 经验是稀缺资源，建议把简历叙事锚定在"具身数据闭环 PM + Function Owner"而非"具身算法工程师"。

具体证据：

  • ShareRobot 51,403 episodes × 3 维标注（planning+affordance+trajectory）是 BAAI 的数据基石，本质就是 AD PM 最擅长的"大规模+多维度对齐标注"。
  • AirExo-2 "人示教→伪机器人数据"是国内降低具身数据成本最关键的工程创新之一，这跟 AD 的"数据采集车队/仿真合成"是同构问题。
  • EmbodiedScan 100万 ego-centric 视图 + 100万语言 prompt是大规模多任务标注的范例，AD 数据闭环 PM 最擅长的"数据采集→清洗→多任务标注→评测闭环"正是具身当前最缺的。

反事实：如果你去卷模型架构（清华/上海 AI Lab 红海），你的 4 年 PM 经验几乎不加分；如果你去做数据闭环 PM，你的经验直接对标 ShareRobot/AirExo-2/EmbodiedScan 的 owner，是结构性稀缺。

洞察二："分层大脑" vs "端到端" 的判断力可零成本迁移

AD 里你已经在端到端 vs 模块化上有判断力；具身领域 RynnBrain(分层 VLM+VLA) 与 HoloMotion(小脑) + HoloAgent(编排) 是分层派，OpenVLA/Pi0 是端到端派，可用同一套"可解释性 / 可调试性 / 数据效率 / 部署成本"四维框架去判断，几乎零迁移成本。
四维框架分层大脑（RynnBrain/HoloAgent/RoboOS）端到端 VLA（OpenVLA/π0/GR00T）
可解释性高（感知/规划/控制可分别 debug）低（黑盒）
可调试性高（模块化故障定位）低（需归因到具体层）
数据效率高（感知层可独立预训练）低（需端到端大数据）
部署成本中（多模块编排）低（单一模型）

洞察三：车规级工程纪律是转战具身的差异化竞争力

Sparse4D→SparseDrive→HoloAgent（稀疏空间记忆）是一条清晰的"车端感知范式外溢到具身"的脉络。作为 AD 数据闭环 PM，你比纯机器人背景的人更懂 sparse/deformable/时序融合 的部署价值。HoloMotion 的"机载 300 FPS 遥操作"就是 BPU 部署形态的体现，Sparse4D 的稀疏 query + CUDA deformable 是车端 BPU 友好范式。这是转战具身时"车规级工程纪律"的差异化竞争力。

具体落地：

  • 地平线征程6（BPU Nash，原生支持大参 Transformer，最高 560 TOPS）+ RDK X5（10 TOPS BPU，机器人机载部署）。
  • HoloMotion "机载 300 FPS 遥操作"证明 BPU 已能跑实时人形控制策略。
  • Sparse4D 的稀疏 query 范式本就是为 BPU 车端成本/功耗优化，是车端基因外溢具身的关键资产。

7.2 从根补：数据闭环差异（具身没有车队红利）

难点：具身数据"没有车队红利"。AD 靠几百台车 24h 跑出 TB 级日志，边际成本极低；具身必须靠遥操作 teleop（人控机器人）+ 仿真合成 + 人视频迁移三路并进，单条真机 demo 成本以分钟计（DROID 50 人采 350h）。这意味着 AD PM 的"里程数=数据量"直觉在具身完全不适用——π0 用 10kh 但只 9.1% 开放数据，质量 + embodiment 多样性 + 任务覆盖三位一体才是核心。这条决定了"具身数据闭环 PM"是比"卷模型"更高 ROI 的转战锚点。
  • 需补 1：teleop 工程链路——leader-follower / 手持 / 外骨骼 / VR 四路线按预算/任务场景选型。
  • 需补 2：人体→机器人映射（retarget）——HoloRetarget 3000 FPS 是 sim-to-real 与遥操作放量的瓶颈解法；HoloSMPL 统一动捕源是数据闭环关键基建。
  • 需补 3：contact-rich 失败案例标注——AD 无接触语义，机器人有；力觉/触觉通道是新增且无标准格式的蓝海。
  • 需补 4：分布式采集众包管理——DROID 50 人/564 场景、RoboMIND 多具身体统一平台，多操作者一致性管理、场景多样性配比、数据去重是 AD 里更少遇到的"众包采集"问题。

7.3 从根补：sim-to-real（具身比 AD 更激进）

难点：sim-to-real gap。AD 里 CARLA→真车 gap 是已知难题但可量化；具身 sim-to-real 更难（接触富任务物理不可微、力觉仿真失真）。需补 Isaac Sim/MuJoCo 工程与 domain randomization。EmbodiedGen 的"生成世界训策略→真机 75% 成功"、79.8% sim 成功率，是具身相比 AD 更激进的"生成数据闭环"路线（AD 的 sim 主要做 corner case 注入，具身 sim 可做主训练场）。
  1. Domain Randomization (UDR)——随机化物理/视觉参数训鲁棒 policy。
  2. Adaptive/Active DR (ADR)——根据 policy 进度自适应调整随机化难度。
  3. Dynamics Randomization + 系统辨识——随机化动力学 + 真机数据辨识仿真器参数。
  4. 综述首选：Muratore 2022 Frontiers（sim-to-real 综述）。
