① 一句话定位 + 为什么 PM 必须懂世界模型

世界模型（World Model）是"从过去观测预测未来状态、且可被动作控制"的生成式基础模型。它的关键不在"生成像素"，而在"理解物理因果 + 可被 action 条件化"——这是它和纯视频生成（如 Sora/CogVideoX/Wan2.1）的本质区别。

世界模型之所以 2024-2026 爆发，是因为它同时回答了三个工业级问题：(1) 数据稀缺——长尾/危险场景采集成本极高，世界模型可批量"造数据"；(2) 仿真可信——传统仿真器（CARLA/VTD）需要手工资产，世界模型从真实视频学；(3) 规划闭环——把世界模型当 reward model 或 rollout 环境，可直接训规划器。这三件事恰好是 AD 数据闭环 PM 最熟悉的"采集/仿真/评测"三段，所以世界模型是 PM 转战 Physical AI 的最高杠杆切入口。

这本教材的结构：先把"世界模型是什么"从根上讲清（§2-§3），再盘点所有龙头开源 repo（§4-§7，每个带 URL/架构/数据/算力/可复现），然后横评架构（§8），最后落到数据基建（§9）、训练基建（§10）、数据闭环重塑（§11），并给一份从根补的转战补习路线（§12-§13）。

本书最重要的认知杠杆：不要把"世界模型"和"视频生成"混为一谈。Sora/CogVideoX/Wan2.1/HunyuanVideo 是"视频生成基础模型"——它们不学物理、不可交互、不能被 action 条件化；真正的世界模型（Cosmos / Genie / GAIA / Vista / DriveDreamer）具备可控性 + 物理一致性。PM 在内部清晰区分这两类叙事，避免资源错配，这是"判断力领先于实现熟练度"的典型用武之地。

概念关键区别典型

③ 世界模型的本质：物理一致 + 可控 + 反事实

判断一个模型是否"够格"叫世界模型，看三条硬指标——这是 PM 做选型/竞品分析时的判定框架：

3.1 物理一致性（Physical Consistency）

生成的未来必须服从基本物理：物体不会瞬移、不会穿墙、相机运动符合几何约束、重力/惯性合理。评测难点：没有公认 benchmark。Cosmos-Reason1 自建"物理常识本体（Space/Time/Physics）"是西方为数不多的尝试；GAIA/Genie 基本无公开物理一致性评测。

物理一致性评测是 PM 最该切入的空白点。AD 数据闭环 PM 习惯的"问题定义 + 金标准 + 闭环指标 + 回归门禁"在这里高度稀缺。把 ROVER5.0 的发版/收敛方法论迁移到世界模型物理评测，是差异化定位。建议补的研究：Cosmos-Reason1 论文（arXiv:2503.15558）的 Physical Common Sense Ontology。

3.2 可控性（Controllability）

能否通过 action / 条件变量精确控制生成结果？这是世界模型与视频生成的分水岭。三种典型可控机制：

  • Latent Action Model（Genie 1）——无监督从视频学潜在动作，推理时替换为用户 action。
  • Adaptive Layer Norm 条件化（GAIA-2）——把 ego 速度/曲率作 symlog 编码后通过 AdaLN 注入。
  • Cross-attention 条件化（MagicDrive、Cosmos、Wan2.1）——文本/3D box/HDMap 通过 cross-attn 注入。

3.3 反事实推演（Counterfactual Rollout）

给定一个"如果换条轨迹会怎样"的查询，能否生成对应未来？这是世界模型当reward model / 仿真器的前提。Vista 在不访问 ground-truth action 下对不同动作给 reward；GAIA-2 用 scenario embedding 控制生成；Drive-WM 用"多未来候选 + 图像评估"选最优轨迹。

这三条本质指标的存在理由：世界模型不是"更好的视频生成"，而是"可被规划器/RL agent 当环境用的可交互模拟器"。物理一致性决定它生成的数据是否能上车训练；可控性决定它能否覆盖长尾；反事实决定它能否做规划评估。三者缺一就退化成视频生成。反事实：若一个模型只能生成"统计上像驾驶"的视频但不能被 ego 动作控制，它就是 DriveDreamer v1 的水平——可用作数据增强，但无法做闭环评测。

④ 龙头开源深度盘点：NVIDIA Cosmos

NVIDIA 是 2025 年世界模型开源赛道的事实龙头——唯一把"World Foundation Model + Tokenizer + Video Curator + Guardrail"整条数据闭环平台都开源的玩家。

4.1 NVIDIA Cosmos-Predict1 — 双轨制 WFM 平台 开源Apache-2.0NVIDIA Open Model License

URL：github.com/nvidia-cosmos/cosmos-predict1 · 论文：arXiv:2501.03575 · 算力：10000×H100 × 3 个月 · 数据：2000 万小时原始 → 清洗后 ~10⁸ 训练 clip + 10⁷ 微调 clip

架构（双轨制，这是 Cosmos 最值得学的设计）：

  • Diffusion 轨（DiT 扩散）：Text2World + Video2World，各 7B/14B。用 CV8×8×8 连续 tokenizer（Continuous Video）。
  • Autoregressive 轨（自回归 Transformer）：4B/12B/5B/13B。用 DV8×16×16 离散 tokenizer（Discrete Video）。
  • 视频先压成连续/离散 latent，再预测未来帧——双轨共享 tokenizer 设计哲学。

数据分布（按类别）：驾驶 11%、手部操控 16%、人体运动 10%、导航 16%、第一人称 8%、自然动态 20%、动态相机 8%、合成 4%、其他 7%。

核心创新：

  1. Tokenizer 是核心——CI/DI/CV/DV 四族，空间压缩 8×/16×、时间压缩 4×/8×，总压缩比最高 2048×（8×16×16），比 SOTA 高 8× 压缩且更快（2-12×）。
  2. 时间因果（causal）tokenizer，支持 1:1/3:4/4:3/9:16/16:9 多宽高比。
  3. WFM + Video Curator + Guardrail 三件套全开源——这是工业级数据闭环平台的范式。
  4. Single2MultiView AV——单视角转多视角，直接服务 AD 多相机生成。

可复现性：高度可复现。权重 NVIDIA Open Model License（商用可用、可派生），代码 Apache 2.0；权重/脚本/后训练/微调全开源。注：Cosmos-Predict1 已转维护模式，新主线为 Cosmos 3（在 HuggingFace 上线）。

双轨制的设计逻辑：Diffusion 擅长高保真视频生成（连续 latent 利于像素级细节），AR 擅长长时序一致性 + 多模态控制（离散 token 利于 next-token 范式 + 接 LLM）。Cosmos 把两条路线都开源，让用户按"保真度 vs 可控性"权衡选——这是其他单押一路的玩家（GAIA 押扩散、Genie 1 押 AR）所没有的工程成熟度。读者要建立"双轨不是冗余，是覆盖不同 ROI 点"的认知。

4.2 NVIDIA Cosmos-Reason1 — 物理常识 + 具身推理层 开源

URL：github.com/nvidia-cosmos/cosmos-reason1 · 论文：arXiv:2503.15558 · 尺寸：7B / 56B（多模态 LLM）

架构：多模态 LLM（vision-language），通过长链式推理（long chain-of-thought）输出自然语言具身决策。两阶段训练：Physical AI SFT → Physical AI RL，论文报告两阶段均带来显著提升。

核心创新——把"世界模型"从"生成像素"抬到"生成推理决策"：

  • 用本体（ontology）显式定义物理常识 + 具身推理的评测维度：Physical Common Sense 覆盖 Space/Time/Physics 三域层级；Embodied Reasoning 是跨具身形态的二维本体。
  • 给"世界模型是否真懂物理"提供可量化的 RLAI 范式。
  • 配套自建 benchmark。

用途：给机器人/AV 提供"看视频→输出下一步具身决策 + 推理链"；可作评测世界模型物理理解能力的上层裁判/teacher。

可复现性：代码 + 预训练权重均在 NVIDIA Open Model License 下开源。可复现推理与 benchmark。

Cosmos-Reason1 的战略意义是补全世界模型评测缺位。除它和 DreamerV3（用 150+ 标准 RL 任务）外，GAIA/Genie 几乎无公认 benchmark。这恰好是 AD 数据闭环 PM 习惯的"问题定义 + 评测体系"能补强的地方——把 ROVER5.0 的发版/收敛方法论迁移到世界模型物理评测上，是差异化定位。反事实：若团队只追生成质量（FID/FVD），会做出"画面漂亮但物理穿模"的世界模型，上车就翻车。

4.3 NVIDIA Cosmos-Tokenizer — 隐形护城河 已归档但可用

独立仓 github.com/NVIDIA/Cosmos-Tokenizer（已归档但可用）。四族 tokenizer：

族类型空间时间总压缩用途
CI连续图像8/16——图像生成
DI离散图像8/16——AR 图像
CV连续视频84/8最高 2048×（8×16×16）Diffusion 视频生成
DV离散视频8/164/8最高 2048×AR 视频预测
为什么 tokenizer 是世界模型的"隐形护城河"：视频模型训练算力几乎正比于序列长度。Cosmos 把视频压 2048×，意味着同等算力下能训多 8 倍数据或多 8 倍参数。GAIA-2 用 32×8× 连续 latent（~400×）、Genie 1 用 ST-ViViT——谁掌握更好的视频 tokenizer，谁的训练算力效率就高一个数量级。这是 PM 评估"换 tokenizer 是否值得"的硬指标，是必补的模型侧硬知识。

⑤ 龙头盘点：西方闭源 / 半开源

5.1 Google Genie 1 / 2 / 3 — action-controllable 世界模型奠基 Genie 1 算法+社区复现Genie 2/3 完全闭源

论文：arXiv:2402.15391（Genie 1）· 博客：Genie 2 blog · Genie 1 算力：256×TPUv5p

Genie 1 架构（三件套，~11B 参数）：

  • ST-ViViT 时空视频 tokenizer（200M 参数，VQ-VAE，1024 码本）——时空因子化 transformer，比 C-ViViT 省显存（0.9GB vs 1.6GB）。
  • 自回归 Dynamics Model（10.1B）——预测下一 latent 状态。
  • Latent Action Model（LAM，300M，VQ-VAE，8 个离散潜在动作）——无监督从视频推断潜在动作。

数据：30000 小时互联网 2D 平台游戏视频，从 5500 万 clip（244k 小时）经学习分类器筛选出 680 万 clip，10 FPS、160×90。

核心创新：

  1. 完全无监督从无标注视频推断"潜在动作"——推理时丢弃 LAM、替换为用户动作即可控制。这是 "action-controllable 世界模型"的奠基范式。
  2. ST-ViViT 时空因子化。

Genie 2 / Genie 3：从 AR 转向扩散世界模型；Genie 2 可"任意图像→3D 可玩、动作可控、可持续 1 分钟"；Genie 3 为通用世界模型。架构/训练/数据均未披露。

可复现性：官方未开源。社区复现——Open-Genie（PyTorch）、GenieRedux（INSAIT）、Jafar（JAX）。算法可近似复现，权重不可。

Latent Action Model 是世界模型最重要的概念之一。传统思路需要给每个视频帧配 action 标签（成本极高），Genie 用 VQ-VAE 把连续 action 离散成 8 类潜在动作——从"看视频"自动学。这意味着任何无标注视频都可作为世界模型训练数据，把数据成本从"标注数据"降到"原始视频"。AD PM 可对比：你做 corner case 标注花的人工，在 LAM 范式下可大幅降低——这是降低数据成本的根本性创新。

5.2 DeepMind DreamerV3 — 模型基 RL 世界模型原点 完全开源Apache-2.0

URL：github.com/danijar/dreamerv3 · 论文：Nature 2025（s41586-025-08744-2） · 算力：单 GPU 可跑

架构：RSSM 循环状态空间模型（latent dynamics）+ decoder/reward/continue heads；actor-critic 在"想象轨迹"上训练。与前代关键改动：symlog 预测、free bits、自动熵缩放、去掉 imagination 内 critic 分布——使其固定超参跨域可训。

训练：单一配置，无超参搜索；可在单 GPU 跑。

数据：无外部视频；从 agent 自身与环境交互的 rollout 在线学习。覆盖 150+ 任务（DM Control/Atari/Crafter/ProcGen/Minecraft 等），含连续/离散动作、2D/3D、视觉/低维输入。

核心创新：首个固定超参跨 150+ 域达到 SOTA 的算法，首次无调参解 Minecraft diamond——证明"世界模型 + 想象训练"可作为通用 RL 范式。

可复现性：完全开源（Apache 2.0），代码完整、文档清晰、可单卡复现，是最易上手的"世界模型"入门项目。

DreamerV3 是教学/研究的"世界模型原点"。它定义了世界模型最朴素的形式："在 latent 空间预测未来状态 + 想象训练"。所有后来的视频世界模型（Cosmos/GAIA/Genie）都是把这个核心思想从 latent 空间抬到像素/视频空间。读者从这里开始建立心智模型最纯粹——单卡可跑、150+ 任务、Nature 论文。反事实：若直接从 Cosmos 14B 入手，会被工程复杂度（5D 并行、Tokenizer、Curator）淹没，学不到世界模型的本质。

5.3 Wayve GAIA-1 / 2 / 3 — 驾驶生成式世界模型最佳参考 全闭源

论文：GAIA-1 arXiv:2309.17080 · GAIA-2 arXiv:2503.20523 · Org：Wayve（英国伦敦） · GAIA-1 参数：9B

GAIA-2 架构（最新公开技术细节，是"AD 世界模型产品化"的最佳参考实现）：

  • Video Tokenizer：85M 编码器 + 200M 解码器（VAE，32× 空间 + 8× 时间下采样，64 通道连续 latent，总压缩 ~400×）。
  • World Model：8.4B 空间-时间因子化 transformer（4096 维、32 头、22 层），flow matching 替代 DDPM，adaptive layer norm 做动作条件、cross-attention 做其他控制。
  • 从 GAIA-1 的离散 token 改为连续 latent；支持 5-6 路环视联合生成。

数据：约 2500 万段 2 秒视频序列（2019-2024），覆盖英国/美国/德国，3 款轿车+2 款厢式，5-6 路相机，20/25/30Hz，输入分辨率 448×960/路。

核心创新——丰富的结构化条件（这是 PM 视角的"需求镜像"）：

  • 自车速度+曲率（symlog 编码）；动态 agent 3D box；天气/限速/车道/红绿灯/路口等元数据。
  • 相机内外参；CLIP 文本/视觉嵌入；scenario embedding（来自 Wayve 私有驾驶模型）。
  • flow matching 训练更稳；rolling window 解码保证多帧一致性。

可复现性：三代全部闭源——论文 + 博客 + demo 视频；无权重、无官方代码、无私有数据。被 Oxera 报告与多篇综述明确归类为 closed。不可复现。

GAIA-2 的结构化条件几乎就是 AD 数据 schema 的字段清单。研究它可反推你自己的数据闭环该采集哪些元数据——这是 PM 视角的"需求镜像"。对比你的 HilPerformancePlatform 数仓 schema，看缺哪些字段（天气标签？红绿灯状态？路口拓扑？scenario embedding？）。GAIA-2 闭源反而是优势：你不会被代码细节带偏，只能从论文反推产品需求，训练的就是 PM 的需求抽象能力。

6.1 DriveDreamer 系（v1 / 2 / 4D）— 真实驾驶世界模型开创者 开源Apache-2.0

v1：github.com/JeffWang987/DriveDreamer（ECCV 2024）· v2：github.com/f1yfisher/DriveDreamer2（AAAI 2025）· 4D：github.com/GigaAI-research/DriveDreamer4D（CVPR 2025） · Org：GigaAI + CASIA + 清华

DriveDreamer v1：首个完全从真实驾驶场景建立的世界模型（区别于游戏/仿真器环境的 GAIA-1）。两阶段训练：先学结构化交通约束（HDMap/3D bbox/轨迹），再预测未来状态。数据：nuScenes。

DriveDreamer-2：引入 LLM 接口——LLM 把用户文本查询转成 agent 轨迹 → 生成符合交规的 HDMap → Unified Multi-View Model 出时序一致多视角视频。首个能用自然语言定制驾驶视频的世界模型。FID 11.2、FVD 55.7，比 SOTA 相对提升 ~30%/50%。生成数据可使下游 3D 检测 +4%、跟踪 +8%。

DriveDreamer4D：用世界模型先验合成额外多视角数据（变道、前进-后退轨迹）来增强 4D 场景重建——首次把"世界模型当数据机器"喂给 4D 重建。

可复现性：代码均开源（Apache-2.0）。v1 repo 有训练/数据准备文档但未明确放预训练权重；v2/4D 有代码与权重。整体可复现性中等偏上，但需自备 nuScenes。

6.2 OccWorld — 3D occupancy 自回归世界模型 开源Apache-2.0

URL：github.com/wzzheng/OccWorld（ECCV 2024，清华） · 算力门槛：单张 RTX 4090（24GB）可训

架构：GPT 式自回归生成——先用 VQ-VAE 把 3D occupancy 离散化为 token，再用 transformer 自回归预测"下一帧场景 + ego 运动"的联合演化。

数据：nuScenes + Occ3D 的 3D occupancy 标注；兼容 SelfOcc/TPVFormer/SurroundOcc 的 occupancy 数据。

核心创新：把世界模型从"像素空间"搬到"3D occupancy 离散 token 空间"，自监督预测未来场景与 ego 联合演化；可预测周围 agent 运动与可行驶区域，显示"理解场景而非记忆数据"。局限：难以预测新进入视野的车辆。

可复现性：Apache-2.0；权重 + train.py/eval/visualize 全释出；硬件门槛低。是 PM 入门 AD 世界模型的最佳实验体。

OccWorld 把"世界模型"从像素抬到 occupancy——这是认知杠杆。像素世界模型（DriveDreamer/GAIA）关心"画面像不像"，occupancy 世界模型关心"几何对不对"。对 AD 而言，occupancy 是更接近规划/可行驶区域判断的表示。读者要建立："表示空间决定下游用途"的直觉——这是补强点 2 的核心。

6.3 Vista + GenAD — OpenDriveLab 世界模型矩阵 开源Apache-2.0

Vista：github.com/OpenDriveLab/Vista（NeurIPS 2024） · GenAD：github.com/OpenDriveLab/DriveAGI（CVPR 2024 Highlight） · Org：OpenDriveLab / 上海 AI Lab

Vista 架构：Latent diffusion（基于 Stability AI generative-models）；支持多模态动作条件——转向角、速度、指令、轨迹、目标点。

Vista 核心创新：强泛化的驾驶世界模型——高保真未来预测 + 连续长时程外推 + 多模态动作可控 + 可在不访问真值动作下对不同动作给 reward（即可作 reward model 评估驾驶行为）。是 GenAD 的后续升级。

GenAD（CVPR 2024）：大规模 video prediction 预测模型，用 OpenDV-YouTube（1700+ 小时真实驾驶视频，nuScenes 的 ~300 倍）做 web-scale 预训练。提供 OpenDV-mini（25 小时 / 44GB raw / 390GB img）供快速上手。

可复现性：Vista 代码 Apache-2.0，权重 vista.safetensors 在 HuggingFace + Google Drive（v1.0，2024/06）；门槛相对低、社区活跃。GenAD 数据/下载脚本全释出，模型本体权重在仓库内未完整释出（后续以 Vista 形式释出）。

Vista + GenAD + WorldEngine + ReSim + SimScale 构成 OpenDriveLab 世界模型矩阵，是国产里最"产品化、工程化、贴近 AD 数据闭环"的世界模型组合。它们分别覆盖生成（Vista）、表征预训练（GenAD）、后训练数据引擎（WorldEngine）、可靠仿真（ReSim）、规模化评测（SimScale）——这五件套与你的 AD 数据闭环工作流天然对齐。强烈建议作为主练习场。反事实：若只学单一 repo（如 Vista），会错过 WorldEngine 把"世界模型当后训练数据引擎"的产品定位——这才是 PM 最该关注的"数据闭环 2.0"。

6.4 Drive-WM — 多视角 + 端到端规划兼容 开源Apache-2.0

核心创新：首个与端到端规划兼容的驾驶世界模型；首个生成高保真多视角视频的驾驶 WM；用"多未来候选 + 图像评估"做轨迹决策。

6.5 MagicDrive / Panacea / WoVoGen — 可控生成三件套 开源

MagicDrive：github.com/cure-lab/MagicDrive（ICLR 2024，CUHK，1167 stars） · Panacea：github.com/wenyuqing/panacea（CVPR 2024/2025） · WoVoGen：github.com/fudan-zvg/WoVoGen（ECCV 2024）

MagicDrive：扩散模型；用 cross-attention + additive encoder branch 注入文本/相机姿态/3D bbox/road map条件；cross-view attention 保证多视角一致性。强调"多样化 3D 几何控制"，解决纯 BEV 条件对高度/遮挡/路面高程控制不足。可生 60 帧长视频。复现度高（多档 checkpoint 在 HF：flymin/MagicDrive-*）。

Panacea/Panacea+：扩散 + 4D attention + 两阶段生成 pipeline；ControlNet 框架用 BEV layout 精细控制。强调 Consistency（时序+跨视角）+ Controllability（与标注对齐）；可调天气/时间/场景；生成带自动标注的无限合成数据。

WoVoGen：World Volume-aware Diffusion；两阶段——(i) 据车辆控制序列"envision"未来 4D temporal world volume（HD map + occupancy），(ii) 据该 4D world volume + 传感器关联生成多相机视频。引入显式 4D world volume 作为生成基础元素。

7.3 视频生成底座（非世界模型，但是世界模型的训练底座）

Wan2.1 / Wan2.2（阿里通义万相）— 国产开源视频生成事实标杆 开源Apache-2.0

URL：github.com/Wan-Video/Wan2.1 · github.com/Wan-Video/Wan2.2 · 尺寸：1.3B（dim1536/30层/12头）+ 14B（dim5120/40层/40头）；Wan2.2 升级为 MoE（A14B）

架构：Flow Matching + DiT。T5 多语言文本编码器 + 每层 cross-attention；时间嵌入经共享 MLP 预测 6 个调制参数。自研 Wan-VAE（3D causal VAE）做时空压缩 + 时间因果性，可编解码任意长 1080P 视频不丢历史时序信息。

训练：数据"数十亿级图像+视频"，H800 级集群训练。

核心创新：首个支持中英文双语文字渲染效果的开源视频生成模型；展示了视频生成的 scaling law（1.3B→14B 性能跨越）；VBench 登顶，被多家评测认为超越闭源 Sora。生态最完整（VACE 编辑、FLF2V 首尾帧、ComfyUI/diffusers 深度集成、FSDP+xDiT USP 多卡推理）。

可复现性：中-高。推理/微调脚本全开源（Apache-2.0），社区有 VideoX-Fun 全参数训练教程；但 14B 从零训练需 H800 级算力，企业级微调可行。

社区推理显存：1.3B 仅需 8.19GB 跑 480P；14B 720P 需 65-80GB（H100 级）。

HunyuanVideo（腾讯混元）— 开源最大视频模型之一 开源Apache-2.0

URL：github.com/Tencent/HunyuanVideo · 尺寸：13B · 推理显存：720p×129f 需 60GB，544p×129f 需 45GB（提供 FP8 量化）

架构：Dual-Stream → Single-Stream Transformer + Full Attention（文本 token 与视频 token 先独立处理后融合）+ Causal 3D VAE（4/8/16 压缩）+ MLLM 文本编码器（decoder-only 多模态大模型，而非 CLIP/T5）。用 3D RoPE。

VAE 对比（MCL-JCV PSNR）：HunyuanVideo 35.39 vs Cosmos-VAE 32.76 vs CogVideoX-1.5 33.22 vs OpenSora-1.2 30.15——开源最强 3D VAE。

核心创新：双流→单流 DiT 设计；MLLM 当文本编码器（语义强于 T5/CLIP）；AngelPTM 5D 并行 + 99.5% 训练稳定率，是当前开源里工程基建披露最完整的之一。

训练数据清洗管线（PM 必学）：Dover 美学 + 清晰度模型 + 光流运动速度预测 + 场景切分（PySceneDetect + Transnet v2）+ OCR 去文字 + YOLOX 风格水印/logo 检测 + 14 类相机运动分类器。Caption 用自研 VLM 生成结构化 JSON（短/密描述、背景、风格、镜头、光照、氛围）。

CogVideoX（清华 THUDM）— 早期开源 T2V 标杆 2B Apache-2.0 / 5B 自定义

URL：github.com/THUDM/CogVideo · 尺寸：2B / 5B（CogVideoX1.5-5B 支持 10s）

架构：Expert Transformer（专家 Transformer）+ 3D Causal VAE（4×8×16 压缩 = 时间4 / 空间8 / 通道16）。Transformer 内部用"专家注意力"，文本专家分支与视频专家分支解耦，再融合。3D RoPE + 可学习位置嵌入。

训练：5B BF16；传闻 ~224×H800 级别（仓库/论文未直接确认）。约 3500 万高质量视频片段（平均 6 秒/段）。

核心创新："专家 Transformer"把文本与视频注意力解耦显著降低噪声；3D Causal VAE 几乎无损重建；推理优化好（2B 在 GTX 1080Ti 可跑，5B 在 RTX 3060 可跑）。

Expert Transformer 的设计哲学：把"理解专家"和"生成专家"解耦——文本 token 和视频 token 在 Transformer 内部走独立注意力分支，再融合。这避免了跨模态噪声污染，长视频生成漂移更小。CogVideo（2022）是当时首个开源大规模 T2V 模型，CogVideoX（2024）大幅刷新开源 SOTA。读者要建立："专家分离 vs 统一注意力"是 Transformer 设计的核心权衡——HunyuanVideo 走"双流→单流"，CogVideoX 走"专家分支"，Wan2.1 走"全注意力"。

7.4 Open-Sora / Open-Sora-Plan — 低成本训练教材级

Open-Sora v2（HPC-Ai Tech）— $200K 训出商用级 开源Apache-2.0

可复现性：中。代码/数据/权重全开源，但 v1.5 主要在 NPU/MindSpeed-MM 框架，GPU 版本"coming soon"——这是首次在顶级开源视频模型上看到"国产算力锁定"，对复现/二次开发是新的工程约束。

10.2 5D 并行（TP/SP/CP/DP/ZeRO）— 长视频训练命脉

所有头部开源项目都收敛到 5D 并行：

  • TP（Tensor Parallel）——矩阵乘法按 dim 切分到多卡。
  • SP（Sequence Parallel）——序列维度切分；这是长视频（1080P/长时长）训练的命脉。代表：ColossalAI、xDiT USP。
  • CP（Context Parallel, Ring Attention）——上下文窗口环形切分。
  • DP（Data Parallel）——数据并行。
  • ZeRO / ZeroCache——优化器状态/梯度/参数分片，显存换算力。

框架矩阵：HunyuanVideo 用 AngelPTM、Open-Sora 用 ColossalAI、Open-Sora-Plan 用 MindSpeed-MM。HunyuanVideo 报告 99.5% 训练稳定率靠自动容错+checkpoint。

为什么 SP 是长视频命脉（类比 AD 长序列感知）：视频 token 化后序列长度爆炸（10s 1080P 视频经 4×8×16 压缩后仍有数十万 token），单卡装不下。SP 把序列切成多段分到多卡，每卡只算自己那段注意力，再 all-gather 合并——和 AD 长序列感知里的"序列并行"完全同构。读者类比：AD 训练里你处理过 BEV 时序融合的序列长度问题，世界模型的 SP 是把同一思想抬到视频 token 级。这是"训练基建让你从数据 PM 升级为算力/并行 PM"的桥梁。

10.4 训练经济学（Open-Sora v2 透明化）

⑪ 世界模型如何重塑数据闭环

这是本教材对 PM 最重要的一章。世界模型不是"另一种模型"，而是"数据闭环 2.0"——它把"造数据"从补充变主力，把"仿真器"从手工资产变学习式，把"评测"从开环变闭环。

11.2 Real-to-Sim-to-Real 闭环

世界模型把"real → sim → real"打通：

  1. Real → Sim：从真实视频训练世界模型（GAIA-2 用 25M 段私有驾驶序列）。
  2. Sim → Real：世界模型生成合成数据，反哺真实模型训练。
  3. Real → Sim（再）：真实模型在仿真里跑出新 failure case，再回真实数据补。

DriveDreamer4D 是这个闭环的典型实例：用世界模型先验合成额外多视角数据来增强 4D 场景重建，重建结果又可作为新训练数据。

11.3 仿真器 / Reward Model 化

这是世界模型最接近端到端规划的用法：

  • 当仿真器：Vista 用世界模型生成可控未来，规划器在不同动作下 rollout，看哪个未来最优。
  • 当 reward model：Vista 在不访问真值 action 下对不同动作给 reward——这绕开了 RL 的 reward 设计难题。
  • 当闭环评测环境：GAIA-2/Cosmos 都把"合成危险场景做闭环评测"作为核心卖点。OpenDriveLab 的 ReSim + SimScale 是这条路线的产品化。
世界模型当 reward model 的杠杆：RL 的核心难题是 reward 设计（自动驾驶里"安全/舒适/合规"如何量化？）。世界模型给出了新答案：让世界模型预测"如果走这条轨迹，下一秒会不会撞"——把 reward 设计转化为"未来预测"。Vista 和 GAIA-2 都走这条路。读者要建立："世界模型让 RL reward 从手工规则变数据驱动"的认知——这是端到端规划的新范式。

12.1 必补 1：扩散模型底层（从根补，不只是术语）

AD 背景 PM 多熟悉 BEV/Occupancy/端到端判别式范式，但对扩散过程不熟。补习路径：

  1. DDPM（2020）原始论文——理解前向加噪 + 反向去噪。
  2. DDIM（2021）——理解非马尔可夫采样加速。
  3. Score-based / SDE——理解连续化视角。
  4. Rectified Flow / Flow Matching（2022-2023）——理解直路径优化，Sora 之后事实标准。
  5. Latent Diffusion（LDM, 2022）——理解为什么在 latent 空间扩散（VAE 压缩 + 扩散）。
扩散模型的因果链（先因果后术语）：(1) 想生成复杂数据分布但直接建模 P(x) 难；(2) 那就反向走——从简单分布（高斯噪声）出发，学一个"逐步去噪"的过程，最终把噪声变成数据；(3) 训练时给真实数据加噪声、让神经网络学"预测加了多少噪声"；(4) 推理时从纯噪声开始、反复去噪得到生成样本。核心是"反向去噪过程"，不是"加噪过程"——加噪是固定的（用预定义的 noise schedule），学的是去噪网络。读者记住："扩散 = 学一个能从噪声还原数据的神经网络"，这就是因果本质。

12.2 必补 2：DiT 为何取代 U-Net

因果链：

  1. 扩散模型的核心是去噪网络 ε_θ(x,t)，传统用 U-Net（CNN + 跳连）。
  2. U-Net 的归纳偏置（局部性、平移不变性）对图像有用，但限制了 scaling。
  3. DiT（Peebles & Xie, 2023）证明 Transformer 也能做去噪网络，且遵循 scaling law——参数越多，FID 越低。
  4. Transformer 的优势：统一架构（图/文/视/音同构）、易扩展、易并行。
  5. 视频进一步要求时空建模，U-ViT/ Latte 把 DiT 搬到视频潜空间。
DiT 取代 U-Net的存在理由：scaling law。U-Net 不遵循 scaling law（参数到一定规模收益递减），DiT 遵循——这是 LLM 路线在视觉的复刻。Sora 用 DiT、所有 2024+ 视频模型（CogVideoX/HunyuanVideo/Wan2.1/Open-Sora）都用 DiT。反事实：若坚持 U-Net，视频模型会卡在 1B 参数量级，无法 scale 到 13B/14B。

12.3 必补 3：空间 + 时间注意力的设计权衡

视频 Transformer 的核心设计选择：

  • 2+1D 分离（CogVideoX 早期、Open-Sora v1.0）——空间注意力和时间注意力分开做，省算力但可能丢时空耦合。
  • Dense 3D 统一（CogVideoX 后期、HunyuanVideo、Wan2.1）——空间+时间联合注意力，质量好但算力爆炸。
  • Skiparse / Shifted Window（Open-Sora-Plan、Open-Sora v1.3+）——稀疏注意力，性能接近 Dense 3D 但提速 35%+。

12.4 必补 4：视频数据闭环（你的强项迁移）

已在 §9 详述。核心迁移点：

  • 视频清洗 = 你做过的数据质检（把"corner case 挖掘"换"低质/水印/运动模糊过滤"）。
  • caption schema = 你做过的标注 schema 设计。
  • caption 质量飞轮 = 数据飞轮。
  • 训练稳定率 SLA = 闭环 SLA。

⑭ 最深洞察 + 关键决策 rationale

14.1 三大最深洞察

洞察 1：Tokenizer 是世界模型的"隐形护城河"，比模型架构更难追赶

NVIDIA Cosmos Tokenizer 把视频压缩到 2048×，比 SOTA 高 8× 压缩且更快。这意味着同等算力下能训多 8 倍数据或多 8 倍参数。GAIA-2 用 ~400×、Genie 1 用 VQ-VAE——压缩比直接决定训练算力效率。谁掌握更好的视频 tokenizer，谁的世界模型 ROI 就高一个数量级。这恰是 PM 评估"换 tokenizer 是否值得"的硬指标，是必补的模型侧硬知识，也是 NVIDIA 在开源赛道的核心壁垒。

洞察 2：数据闭环同构性——世界模型就是"数据闭环 2.0"

AD 数据闭环 PM 的核心能力（长尾挖掘、场景挖掘、数据合成、Corner Case 治理）与世界模型"当数据机器"的定位（DriveDreamer-2/4D、WorldEngine）完全同构。传统闭环"采集→标注→训练→评测→回流"的边际成本几乎不降；世界模型驱动的闭环"少量采集 → 批量合成 → 自动标注 → 训练 → 闭环评测 → 长尾回流"的边际成本接近零。PM 可直接把世界模型定位为"生成式数据闭环"产品，把"仿真场景生产 + 长尾补充 + 评测资产"作为 Function Owner 的产品边界——这是 2025-2026 最热的 Physical AI 叙事。

洞察 3：评测缺位 = PM 高 leverage 切入点

除 Cosmos-Reason1 自建物理常识本体 + benchmark、DreamerV3 用 150+ 标准 RL 任务、Cam4DOcc 是 benchmark 级工作外，GAIA/Genie 缺乏公认 benchmark。FID/FVD 评生成质量、occupancy IoU 评预测，但缺跨模型可比的统一 leaderboard。这恰是 PM 强项——AD PM 习惯的"问题定义 + 金标准 + 闭环指标 + 回归门禁"在世界模型赛道高度稀缺。把 ROVER5.0 的发版/收敛方法论迁移到世界模型物理评测，是差异化定位，也是"判断力领先于实现熟练度"的最直接变现。
